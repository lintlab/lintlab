# lintlab

**Small, reliable data tools that do one job well: clean inputs, clean JSON, fair prices.**

lintlab builds focused developer tools:

- **Apify Actors** that turn public APIs and open data into clean, normalized JSON (pay-per-event, no subscriptions).
- **Small utilities** with predictable pricing and documented output.
- **Fixes for open-source projects**, tested before the PR is opened.

## Live tools

All tools, with API examples: **https://lintlab.pages.dev**

| Tool | What it does | Price |
|---|---|---|
| [Screenshot + Visual Diff](https://apify.com/lintlab/screenshot-diff) | Full-page, viewport or element screenshots with an optional pixel diff against a baseline | $0.004 per capture, $0.002 per diff |
| [SEO Audit & Broken Link Checker](https://apify.com/lintlab/seo-site-qa) | HTTP-only technical SEO audit: titles, meta, headings, canonicals, robots, internal links, duplicates | $0.004 per audited page; failed pages free |
| [PDF to Markdown & Text Extractor](https://apify.com/lintlab/pdf-to-markdown) | Public PDF URLs to page-aware Markdown or text with links, simple tables and metadata (no OCR) | $0.003 per processed PDF; failures free |
| [Sitemap Validator & URL Extractor](https://apify.com/lintlab/sitemap-doctor) | Finds sitemaps via robots.txt, validates every file (XML, gzip, indexes), extracts URLs with lastmod, diffs runs, optional status checks | $0.001 per sitemap file, $0.0003 per URL, $0.0005 per status check |

All run on Apify with pay-per-event pricing, so you (or your AI agent) pay only for results.

Every tool is tested before release.
